# mirzabot-patches

🌐 [English](./README.md) | فارسی

ضمن تشکر از [توسعه‌دهنده‌ی ربات میرزا](https://github.com/mahdiMGF2/mirzabot) که تغییرات بر روی اسکریپت ورژن **0.3.1** رایگان ایشان اعمال شده است. ورژن اصلی مورد نظر که حتماً بایستی نصب باشد، نگارش **0.3.1** است.

مسئولیت استفاده از این اسکریپت بر عهده‌ی نصب‌کننده است. خود اسکریپت از پوشه‌ی اصلی روی سرور ربات شما پشتیبان تهیه می‌کند، اما پشتیبان‌گیری از پایگاه داده را حتماً مدنظر داشته باشید.

پچ‌های سفارشی برای [mahdiMGF2/mirzabot](https://github.com/mahdiMGF2/mirzabot) — شامل رفع باگ‌های پایداری و افزودن پشتیبانی کامل از ایموجی‌های پرمیوم متحرک تلگرام (روی دکمه‌ها و متن پیام‌ها).

## برای آشنایی با نحوه‌ی اعمال و درج ایموجی‌ها حتماً راهنمای زیر را ببینید

جزئیات کامل: [DEPLOY_NOTES.fa.md](./DEPLOY_NOTES.fa.md)

## نصب سریع

حتماً بعد از ورود به منوی نصب اسکریپت اصلی، از منوی شماره‌ی ۲، ورژن ۰.۳.۱ را انتخاب کنید. اگر از قبل این ورژن را نصب دارید، به مرحله‌ی نصب پچ بروید. برای ورژن‌های دیگر ممکن است برنامه به‌درستی کار نکند، پس حتماً حتماً قبل از آن از دیتابیس SQL خود بکاپ بگیرید.

خود اسکریپت پچ از فولدر اصلی ربات پشتیبان تهیه می‌کند و آن را در همان مسیر اصلی پوشه‌ی ربات قرار می‌دهد. امکان بازیابی این پوشه در صورت هر تغییری از منوهای این اسکریپت وجود دارد.

```bash
# ۱. نصب استاندارد mirzabot (از ریپوی اصلی) — از منو نسخه‌ی 0.3.1 را انتخاب کنید
curl -o install.sh -L https://raw.githubusercontent.com/mahdiMGF2/mirzabot/main/install.sh && bash mirza install version 0.3.1
```

```bash
# ۲. اعمال این پچ‌ها
curl -o apply-patches.sh -L https://raw.githubusercontent.com/techelik/mirzabot-patches/main/apply-patches.sh
sudo bash apply-patches.sh
```

## چیزی که این پچ‌ها اضافه می‌کنن

- رفع باگ حساسیت به حروف بزرگ/کوچک `parse_mode` (که مانع نمایش تگ‌های HTML/ایموجی پرمیوم می‌شد)
- رفع ریسک هنگ‌کردن سرویس در فراخوانی‌های درگاه پرداخت
- تنظیم خودکار PHP-FPM برای پایداری بیشتر
- سیستم کامل مدیریت ایموجی پرمیوم از داخل خودِ ربات، برای:
  - دکمه‌های اصلی کیبورد
  - دسته‌بندی و نام تک‌تک آموزش‌ها
  - محصولات و دسته‌بندی‌های فروشگاه
  - متن آزاد پیام‌ها (قوانین، خوش‌آمدگویی و...)

این پروژه یک فورک کامل نیست؛ کنار نصب رسمی mirzabot اجرا می‌شود و `config.php` را هیچ‌وقت دست نمی‌زند.
