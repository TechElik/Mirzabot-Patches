## روش‌های نصب — کدومو انتخاب کنم؟

دو راه برای رسیدن به یه ربات کاملاً پچ‌شده هست: مستقیم `install.sh` رو برای یه نصب تازه اجرا کنی، یا `apply-patches.sh` رو بزنی که یه منوی تعاملی داره و همه‌ی حالت‌ها رو پوشش می‌ده (نصب تازه، آپدیت نسخه‌ی قدیمی، پچ کردن نصب ۰.۳.۱ موجود، و مدیریت بکاپ).

### 🆕 روش A: نصب کامل و تازه (برای کسی که اصلاً ربات نصب نداره)

این اسکریپت، **همون نصاب رسمی mirzabot** رو نصب می‌کنه، با این تفاوت که تمام فایل‌ها از قبل شامل فیکس‌ها و فیچرهای ایموجی پرمیوم هستن — نیازی به مرحله‌ی جداگانه برای اعمال پچ نیست.

```bash
curl -o install.sh -L https://raw.githubusercontent.com/TechElik/Mirzabot-Patches/main/install.sh && bash install.sh
```

بعد از اجرا، دقیقاً طبق همون منوی همیشگی نصاب mirzabot جلو برید (دامنه، توکن ربات، اطلاعات دیتابیس و...).

### 🔧 روش B: منوی `apply-patches.sh` (پیشنهادی — همه‌ی حالت‌ها رو پوشش می‌ده)

```bash
curl -o apply-patches.sh -L https://raw.githubusercontent.com/TechElik/Mirzabot-Patches/main/apply-patches.sh
sudo bash apply-patches.sh
```

این دستور یه منو با ۵ گزینه باز می‌کنه:

| # | گزینه | برای کی |
|---|---|---|
| ۱ | نصب نسخه‌ی پچ‌شده از ابتدا | **اصلاً ربات نصب نداری** — عیناً همون روش A، فقط از داخل منو |
| ۲ | آپدیت نصب موجود به نسخه‌ی پایه‌ی 0.3.1 | ربات رو نصب داری ولی نسخه‌ت **قدیمی‌تر از 0.3.1**ه — با نصاب رسمی، نسخه رو به 0.3.1 می‌رسونه (خودش به‌تنهایی پچ‌های ما رو اعمال **نمی‌کنه**) |
| ۳ | اعمال پچ‌های سفارشی | از قبل **mirzabot 0.3.1** نصب داری — فیکس‌ها و فیچرهای ایموجی پرمیوم رو روش اضافه می‌کنه، با بکاپ خودکار |
| ۴ | بازگرداندن یک بکاپ | برگشت به یکی از بکاپ‌های گرفته‌شده توسط گزینه‌ی ۳ |
| ۵ | حذف بکاپ‌های قدیمی | آزادسازی فضای دیسک |

اگه نسخه‌ات قدیمیه، اول **گزینه‌ی ۲** رو بزن، بلافاصله بعدش **گزینه‌ی ۳** — این مسیر کامل از یه نصب قدیمی تا یه نصب کاملاً پچ‌شده‌ست.

**⚠️ نکته‌ی مهم:** این پچ‌ها فقط روی نگارش **0.3.1** تست شده‌ن. اگه نسخه‌ی دیگه‌ای نصب دارید، ممکنه به‌درستی کار نکنه — حتماً قبلش از دیتابیس SQL خودتون بکاپ بگیرید.

## چیزی که این فورک اضافه کرده

- رفع باگ حساسیت به حروف بزرگ/کوچک `parse_mode` (که مانع نمایش تگ‌های HTML/ایموجی پرمیوم می‌شد)
- رفع ریسک هنگ‌کردن سرویس در فراخوانی‌های درگاه پرداخت
- تنظیم خودکار PHP-FPM برای پایداری بیشتر
- سیستم کامل مدیریت ایموجی پرمیوم از داخل خودِ ربات، برای:
  - دکمه‌های اصلی کیبورد (شامل لینک دانلود برنامه‌ها)
  - دسته‌بندی و نام تک‌تک آموزش‌ها
  - محصولات و دسته‌بندی‌های فروشگاه
  - متن آزاد پیام‌ها (قوانین، خوش‌آمدگویی و...)
